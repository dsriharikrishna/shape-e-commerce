# Gemini Knowledge Base Rules

When executing tasks, always use the files in the `docs/` directory as your default knowledge base. 
Specifically, refer to and update the following files as needed:
- `docs/frontend.md` for frontend-related architectural decisions and guidelines.
- `docs/logs.md` for maintaining a log of changes, debugging steps, and progress.
- `docs/project_analysis.md` for overall project structure and analysis.

Before starting new work, read these files to understand the current context. Update them to reflect any significant changes you make.
